# AI Project Docs for Scribe

Use these files as project knowledge or custom instructions in Claude, ChatGPT,
or any other LLM workspace that helps you plan, validate, and improve articles
before they go into Scribe.

## Files

- `project-instructions.md` - paste this into the project/system instructions.
- `site-context-template.md` - fill this once per blog/site, then attach it as project knowledge.
- `ideation-and-validation.md` - use for keyword ideas, topic clusters, and idea scoring.
- `article-formulas.md` - reusable article structures and prompt recipes.
- `image-generation-guide.md` - prompt rules for manual image generation.
- `quality-review-checklist.md` - final article validation before approval/publishing.
- `scribe-workflow.md` - how the AI assistant should fit into the Scribe app workflow.

## Safety

Never paste API keys, Strapi tokens, database URLs, auth secrets, encryption keys,
or private credentials into a chat project. Keep secrets in Scribe settings or
your `.env` file only.
